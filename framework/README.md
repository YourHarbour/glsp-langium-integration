# GLSP Langium Integration

An integration framework between [GLSP](https://github.com/eclipse-glsp/glsp) and [Langium](https://github.com/eclipse-langium/langium) to allow for the combination of textual and graphical modeling paradigms in the same model. To be clear, this does not mean multiple views on the same underlying model, but rather an integration of both paradigms.

It is available as a npm package `glsp-langium-integration`.
